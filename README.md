# HashTools.pk - Free Online Tools

🚀 **Live Website:** https://ranag786tech-lang.github.io/hashtools/

A simple, fast and 100% free collection of developer tools. Made for students, developers and everyone.

### 🛠️ Tools Included
1.  **SHA256 Generator:** Convert any text to secure SHA256 hash instantly.
2.  **Strong Password Generator:** Create unbreakable 16-character passwords.
3.  **Text to Binary Converter:** Convert text to binary and back.
4.  **Word Counter:** Count words and characters for assignments.

### 💰 How this website earns?
This site earns via Google AdSense. When users use these free tools, they see ads. Each ad view/click gives small earning.

### 📂 How to Host on GitHub (2 Minutes)
1. Create a new repository named `hashtools`
2. Upload `index.html` file
3. Go to Settings > Pages > Select Branch: main > Save
4. Your site will be live in 1 minute!
